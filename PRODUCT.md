# Product

<!-- impeccable:product-schema 1 -->

## Platform

web

## Stack

HTML, CSS e JavaScript em um único arquivo `index.html`, sem backend. Publicação no GitHub Pages. A escolha do stack foi definida pelo próprio desafio.

## Users

Analistas, estudantes e avaliadores de portfólio que precisam entender rapidamente o desempenho de 100 vendas sanitizadas da Porsche. O cenário principal é uma revisão pontual, em desktop ou celular, com poucos minutos disponíveis.

## Product Purpose

Transformar a base sanitizada em respostas de negócio verificáveis, com filtros combináveis, indicadores de topo e leitura clara dos recortes. O sucesso é abrir a dashboard, identificar os padrões relevantes e reproduzir qualquer número pela tabela de registros.

## Positioning

Uma análise independente, pública e auditável: os dados sanitizados, o tratamento, os gráficos e a tabela ficam no mesmo repositório. O HTML funciona sem backend e os filtros atualizam todos os indicadores e visualizações.

## Operating Context

Projeto do desafio de dashboard da DIO. A fonte é a planilha pública de vendas da Porsche. O uso acontece pelo link do GitHub Pages ou abrindo o arquivo localmente. Não há autenticação, edição de dados ou integração comercial.

## Capabilities and Constraints

- Exatamente três perguntas de negócio, cada uma com visual próprio.
- Filtros por modelo, estado, cidade, ano e método de pagamento.
- Indicadores de vendas, receita, ticket médio e modelo líder.
- Tabela filtrada para conferência dos números.
- Dados embutidos no HTML; nenhum dado cru ou informação sensível deve ser publicado.
- Funcionar sem servidor de aplicação e sem bibliotecas externas de gráficos.

## Brand Commitments

O produto usa o nome Porsche para identificar a base analisada, sem apresentar a dashboard como um canal oficial da marca. A direção visual escolhida pelo usuário é "Motorsport premium": off-white, preto e vermelho, tipografia condensada e gráficos precisos.

## Evidence on Hand

Brief do desafio, planilha pública sanitizada, repositório oficial `digitalinnovationone/dashboard_porsche_sales` e esta implementação. Nenhum depoimento, cliente ou resultado comercial além dos registros da base pode ser exibido.

## Product Principles

1. Toda pergunta deve mudar uma decisão ou revelar um padrão.
2. Filtros e indicadores contam a mesma história.
3. Nenhum número aparece sem uma fonte rastreável.
4. A experiência mobile e o teclado têm prioridade equivalente à desktop.
5. A identidade vem da precisão automotiva, não de efeitos decorativos.

## Accessibility & Inclusion

Controles nativos com rótulos visíveis, foco visível, navegação por teclado, contraste WCAG AA, tabelas alternativas para os gráficos, respeito a movimento reduzido e layout sem overflow horizontal.
